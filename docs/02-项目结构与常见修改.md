# 项目结构与常见修改

本章帮助第一次接触 React 的使用者定位文件。可以把项目理解为：入口文件启动页面，页面组合组件，组件读写数据，样式文件负责外观。

## 先理解目录，再决定从哪里改

| 目录或文件组                | 用通俗的话解释                                | 新手最常见的改动                             |
| --------------------------- | --------------------------------------------- | -------------------------------------------- |
| `client/`                   | 网站在浏览器中运行的全部前端代码              | 改页面、图标、颜色、交互和静态配置时优先查看 |
| `client/src/pages/`         | 每一个完整页面的放置处；当前首页是 `Home.tsx` | 新增“关于页”“使用帮助页”                     |
| `client/src/components/`    | 页面可重复使用的界面零件                      | 将设置面板、资源卡片拆分为独立组件           |
| `client/src/components/ui/` | 模板提供的无障碍通用控件                      | 一般只使用，不建议直接修改                   |
| `client/src/lib/`           | 不直接显示，但负责数据、规则和工具函数        | 改备份格式、搜索引擎或图标匹配               |
| `client/src/data/`          | 首次打开时使用的“出厂资源清单”                | 批量替换默认资源                             |
| `client/public/`            | 原样复制到网站根目录的小型静态配置            | 保留 `.nojekyll`；可放 favicon、robots.txt   |
| `scripts/`                  | 仅在开发机运行的辅助脚本                      | 从原始 HTML 重新导入资源                     |
| `.github/`                  | GitHub 自动化配置                             | 调整 Pages 发布分支、Node 版本或构建动作     |

## 重要文件速查表

| 路径                                              | 功能与作用                                                    | 何时修改                                   |
| ------------------------------------------------- | ------------------------------------------------------------- | ------------------------------------------ |
| `client/index.html`                               | 浏览器入口、标题、描述、图标和根节点                          | 修改网页标题、SEO 描述或 favicon           |
| `client/src/main.tsx`                             | React 启动入口                                                | 通常无需修改                               |
| `client/src/App.tsx`                              | 路由总入口；GitHub 项目页会在 `/sky-navigation/` 下设置路由根 | 新增页面或处理路由问题                     |
| `client/src/pages/Home.tsx`                       | 首页主体，含搜索、视图切换、主题、目录与管理窗口状态          | 调整页面布局和主要交互                     |
| `client/src/components/ArchiveSettingsDialog.tsx` | 分类、书签、批量操作和数据工具的设置窗口                      | 新增管理动作                               |
| `client/src/data/resources.ts`                    | 初始分类与书签数据                                            | 更新出厂资源；日常编辑优先使用页面管理功能 |
| `client/src/lib/archive-store.ts`                 | 本地数据读写、校验、导入和导出                                | 改备份格式或恢复规则                       |
| `client/src/lib/search-engines.ts`                | 站外搜索引擎清单                                              | 增加、删除或更换搜索引擎                   |
| `client/src/lib/category-tree.ts`                 | 多级目录与 SVG 图标匹配                                       | 调整分类层级、展开规则或图标               |
| `client/src/index.css`                            | 全站视觉、独立滚动、响应式断点                                | 修改颜色、字体和各设备布局                 |
| `scripts/extract-resources.mjs`                   | 从原始 HTML 导出初始资源                                      | 再次批量导入资源                           |
| `scripts/publish-gh-pages.mjs`                    | 本地检查后触发唯一 gh-pages 发布工作流                        | 手动刷新 GitHub Pages 发布                 |
| `vite.config.ts`                                  | Vite 构建配置；`base: "./"` 让产物使用相对资源路径            | 修改构建目录、别名、开发端口或静态路径     |
| `.github/workflows/deploy-gh-pages.yml`           | 唯一 gh-pages 发布工作流                                      | 改变 Pages 构建或发布规则                  |

## 常见需求应该改哪个文件

| 你的目标                           | 优先修改的位置                                             | 是否需要检查                   |
| ---------------------------------- | ---------------------------------------------------------- | ------------------------------ |
| 改首页标题、提示语、按钮文案       | `client/src/pages/Home.tsx`                                | 运行 `npm run check`           |
| 修改颜色、宽度、卡片样式、手机排版 | `client/src/index.css`                                     | 至少检查 375px 与桌面宽度      |
| 增加或删除站外搜索引擎             | `client/src/lib/search-engines.ts`                         | 是                             |
| 为分类换 SVG 图标                  | `client/src/lib/category-tree.ts`                          | 是                             |
| 修改恢复出厂值后的默认书签         | `client/src/data/resources.ts`                             | 是，并在浏览器中测试恢复出厂值 |
| 新增管理面板功能                   | `ArchiveSettingsDialog.tsx`，必要时修改 `archive-store.ts` | 是，并测试成功与失败路径       |
| 修复线上路由或资源路径             | `App.tsx`、`vite.config.ts`、平台配置                      | 运行 `npm run build:static`    |

## 修改后的基本检查

每次修改 TypeScript 文件后，先运行 `npm run check`。准备上线前运行 `npm run build:static`，确认产物在 `dist/public`。涉及路由或静态路径时，除检查构建产物外，还要用浏览器实际打开项目页；静态 HTML 返回成功不代表客户端路由一定会渲染首页。

需要部署请继续阅读 [部署与排错](./03-部署与排错.md)；只想管理网址则返回 [新手入门与本地管理](./01-新手入门与本地管理.md)。
