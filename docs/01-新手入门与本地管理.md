# 新手入门与本地管理

本章解释 Sky 导航站如何保存数据，以及页面上的搜索、分类和备份功能分别适合什么场景。它面向只想管理个人资源、暂时不准备修改代码的使用者。

## 网站能做什么

Sky 的储物间将大量外链整理为可浏览、可检索的资源账本。桌面端的左侧分类栏和右侧资源清单是**独立滚动容器**：资源列表滚动时，分类栏仍可保持定位；手机端则将分类栏收纳为抽屉。

| 能力                           | 用途                                  | 数据保存位置                |
| ------------------------------ | ------------------------------------- | --------------------------- |
| 资源浏览、关键词搜索、状态筛选 | 快速定位原始外链                      | 内置资源清单与浏览器内存    |
| 分类管理                       | 新增、重命名、删除和排序分类          | 当前浏览器的 `localStorage` |
| 书签管理                       | 新增、编辑、移动、排序和批量处理      | 当前浏览器的 `localStorage` |
| 数据工具                       | JSON 导入导出、快照、清除和恢复出厂值 | 浏览器与下载的 JSON 文件    |
| 双模式搜索                     | 站内即时筛选，或调用站外搜索引擎      | 不上传书签数据              |
| 紧凑/卡片视图                  | 调整信息密度与阅读方式                | 当前浏览器的视图偏好        |

> **本项目是纯静态前端。** 不同浏览器、不同设备，或清理浏览器站点数据后，本地编辑不会自动同步。进行重要修改前，请先导出 JSON 备份。

## 如何打开管理面板

点击页面右上角的 **“管理”**，即可进入设置窗口。危险操作都会要求确认，避免误删。

| 面板     | 可完成的操作                                               | 典型用途                                   |
| -------- | ---------------------------------------------------------- | ------------------------------------------ |
| 分类管理 | 新建、重命名、上移、下移、删除                             | 新建“设计”“常用工具”等目录，或整理目录顺序 |
| 书签管理 | 新增、编辑、删除、移动、分类内排序、批量移动/删除          | 收录自己的网址，或归档一批已有资源         |
| 数据工具 | 导出 JSON、本地快照、还原快照、导入 JSON、清除、恢复出厂值 | 跨电脑迁移、修改前留档、误删恢复           |

删除分类时，关联书签会转入“未分类”，不会被静默删除。选择“一键清除”会清除当前浏览器的本地编辑；选择“恢复出厂值”则会回到项目内置的初始资源清单。

## 搜索与资源浏览

**站内搜**会立即检索书签标题、分类和小分组，不会打开新页面。**站外搜**会将关键词交给当前选择的搜索引擎，并在新标签中打开结果。默认引擎为 Bing，列表包含 20 个常用国内外搜索入口；最近选择会保存在当前浏览器。

资源账本右上角可切换 **“紧凑”** 与 **“卡片”**。紧凑视图适合扫描大量标题；卡片视图会额外呈现分类、小分组、状态与跳转入口，适合逐项阅读。该偏好保存在 `sky-resource-view`，不会影响其他设备。

左侧目录按“顶层分类 → 资源小分组”呈现。目录在当前版本中是**定位器**：点击分类或分组会平滑滚动到右侧对应模块，右侧始终显示完整资源账本，不会因点击目录而隐藏其他分类。

## 推荐的安全操作顺序

当你要批量调整书签时，先在 **管理 → 数据工具** 中导出 JSON，再点击“保存快照”。完成编辑后，再导出一次 JSON。这样你会同时拥有修改前、修改后的可迁移备份，以及当前浏览器内的快速恢复点。

```text
初始资源 resources.ts
        ↓ 首次打开 / 恢复出厂值
浏览器 localStorage（当前浏览器、当前设备）
        ↓ 管理 → 数据工具
JSON 备份文件（可下载、可跨设备导入）
```

## 手机、平板和桌面端

| 设备范围                      | 主要行为                       | 验收重点                                   |
| ----------------------------- | ------------------------------ | ------------------------------------------ |
| 宽屏桌面（≥ 1160px）          | 左目录与资源账本并排且独立滚动 | 滚动资源时分类栏保持固定；卡片视图保持双列 |
| 笔记本/平板横屏（821–1159px） | 左栏与资源账本双列             | 表单与卡片不横向溢出                       |
| 平板竖屏/手机（≤ 820px）      | 分类栏变为抽屉                 | “目录”“管理”均可打开和关闭                 |
| 窄手机（≤ 540px）             | 设置面板接近全屏，表单单列     | 搜索、批量操作和数据工具无需横向滚动       |
