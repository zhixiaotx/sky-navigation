# Sky 的储物间 · 导航版

> **一个可浏览、搜索、整理、备份和恢复的个人资源导航站。** 它以 React、TypeScript 与 Vite 构建；分类、书签和备份操作默认只保存在当前浏览器，不需要服务器或数据库。

## 快速开始

开始前请安装 **Node.js 22 或更高版本** 与 npm。项目已提供 `.npmrc`；请统一使用 npm，不要混用 pnpm。

```bash
# 1. 进入项目目录
cd sky-navigation

# 2. 安装依赖
npm install

# 3. 启动本地开发服务器
npm run dev
```

| 命令                        | 何时使用                         | 结果                                       |
| --------------------------- | -------------------------------- | ------------------------------------------ |
| `npm run dev`               | 日常修改页面时                   | 启动带热更新的本地开发服务                 |
| `npm run check`             | 修改 TypeScript 后               | 检查类型错误，不生成文件                   |
| `npm run build:static`      | 部署静态站前                     | 构建前端到 `dist/public`，使用相对资源路径 |
| `npm run preview -- --host` | 本地验收静态产物时               | 预览 Vite 构建结果                         |
| `npm run publish:gh-pages`  | 需要手动刷新 GitHub Pages 发布时 | 本地检查后触发唯一 `gh-pages` 工作流       |
| `npm run publish:status`    | 确认自动发布是否结束时           | 显示最近运行状态                           |

## 核心能力与数据边界

网站提供多级分类目录、站内/站外双搜索、紧凑/卡片资源视图，以及分类和书签的本地管理。你可以导入、导出 JSON，保存浏览器内快照，或恢复出厂资源。

> **重要说明：** 本项目的本地编辑不会自动同步到另一台电脑或浏览器。进行重要修改前，请在 **管理 → 数据工具 → 导出 JSON** 保存备份。

## GitHub Pages 当前约定

项目使用唯一的 `.github/workflows/deploy-gh-pages.yml` 工作流，并将 `dist/public` 发布至 `gh-pages` 分支根目录。GitHub Pages 设置应为 **Deploy from a branch → `gh-pages` → `/(root)`**。完整步骤与项目页 404 排错请阅读 [部署与排错](./docs/03-部署与排错.md)。
